# 6-minute portfolio demo script

1. **Business problem (45 sec):** A B2B SaaS team receives leads from multiple sources and needs consistent qualification and routing.
2. **Capture (45 sec):** Submit a lead in the dashboard and show the n8n webhook execution.
3. **Enrichment (60 sec):** Explain mock provider A/B waterfall and clearly state Clay is a reserved V2 connector.
4. **Scoring & routing (60 sec):** Show the transparent ICP criteria, score band and owner assignment.
5. **CRM-ready storage (45 sec):** Show the Supabase lead row and event log. Explain HubSpot upsert is a V2 integration point.
6. **Operations (60 sec):** Show n8n execution history and dashboard KPIs.
7. **Production plan (45 sec):** Explain authentication, retries, alerting, secrets, privacy and outbound approval needed before client production.
